This update covers verified engineering progress during the previous seven days. Work in private repositories is summarized without private links or implementation identities; links to public changes appear directly beside the summaries they support.

## Web Wallet and wallet extension

Improved how the web wallet, the browser extension and its Android app handled stuck payments, recovery words and staking.
- Released wallet extension 0.4.0, its first release since 0.3.0 in June, with Chrome and Firefox builds and their checksums on GitHub. ([PR #227](https://github.com/dusk-network/wallet/pull/227), [Release v0.4.0](https://github.com/dusk-network/wallet/releases/tag/v0.4.0))
- Marked a payment the node never received as "Not sent yet", with a choice to send the same signed payment or drop it. ([PR #219](https://github.com/dusk-network/wallet/pull/219), [PR #1067](https://github.com/dusk-network/web-wallet/pull/1067))
- Asked before sending a payment that had waited when the account had sent something else meanwhile, and held the recovery-word check until every box was filled. ([PR #218](https://github.com/dusk-network/wallet/pull/218), [PR #1065](https://github.com/dusk-network/web-wallet/pull/1065))
- Checked the whole kept history before warning about an unfamiliar recipient, and made "Hold to show words" reveal recovery words only during the hold, on phones in the web wallet. ([PR #222](https://github.com/dusk-network/wallet/pull/222), [PR #1068](https://github.com/dusk-network/web-wallet/pull/1068))
- Named which stake the web wallet's add buttons added to, and laid out the two ways to stake more clearly. ([PR #1077](https://github.com/dusk-network/web-wallet/pull/1077), [PR #1078](https://github.com/dusk-network/web-wallet/pull/1078))

## Dusk-bridge

- Covered BNB Smart Chain in both directions and Ethereum to Dusk in version 1.0.0, and linked the testnet bridge to the mainnet one. ([PR #48](https://github.com/dusk-network/dusk-bridge/pull/48), [PR #49](https://github.com/dusk-network/dusk-bridge/pull/49))
- Added transfers of DUSK and the test stablecoins EURd and USDd both ways between Dusk testnet and Sepolia, with route and balance checks before signing. ([PR #44](https://github.com/dusk-network/dusk-bridge/pull/44))
- Configured Cloudflare hosting for the bridge site, with testnet updated on every merge and mainnet only from a release tag. ([PR #43](https://github.com/dusk-network/dusk-bridge/pull/43))

## Rusk


### Core (Public + Private Repo)

Released versions 1.7.4 and 1.7.5 of Rusk, Dusk's node software, which runs consensus and smart contracts.
- **Private:** Added an opt-in history of contract state to Rusk archive nodes, and strengthened the node's reliability.
- Published both versions on GitHub, 1.7.4 on 18 November and 1.7.5 on 20 November. ([Release dusk-rusk-1.7.4](https://github.com/dusk-network/rusk/releases/tag/dusk-rusk-1.7.4), [Release dusk-rusk-1.7.5](https://github.com/dusk-network/rusk/releases/tag/dusk-rusk-1.7.5))
- Added a setting that kept contract state at every final block on archive nodes, so contract queries could name a past block height.
- Reworked protocol upgrades so one schedule per network set the consensus rules, and tied the compact record of block events to the Cerberus upgrade.
- Consolidated transaction building for the command-line wallet and W3sper, the JavaScript SDK, into one shared component with unchanged formats.
- Simplified the command-line wallet's form screens, and added tests for its local cache.
### Piecrust (Private Repo)

Optimized contract deployment in Piecrust, the virtual machine behind Dusk smart contracts, and strengthened its reliability.
- Added reuse of compiled contract code, so a repeat deployment of the same bytecode skipped compiling it.
- Clarified the rules of the opt-in standard WebAssembly memory mode, and expanded the memory tests and checks for developers.

## Node installer

Released node installer 0.5.25 and 0.5.26, the script that sets up a Dusk node.
- Bundled Rusk 1.7.4 in 0.5.25 and Rusk 1.7.5 in 0.5.26, for mainnet and testnet. ([PR #206](https://github.com/dusk-network/node-installer/pull/206), [Release v0.5.25](https://github.com/dusk-network/node-installer/releases/tag/v0.5.25), [PR #207](https://github.com/dusk-network/node-installer/pull/207), [Release v0.5.26](https://github.com/dusk-network/node-installer/releases/tag/v0.5.26))

## Kadcast (Public + Private Repo)

Hardened Kadcast, the network layer Dusk nodes use to share blocks and transactions, to keep nodes responsive.
- Strengthened how nodes handled and checked incoming messages. ([PR #170](https://github.com/dusk-network/kadcast/pull/170))
- Updated the minimum Rust compiler version for building Kadcast to 1.96.

## App-core package

Released app-core 0.18.0 to 0.20.0, the shared code behind both wallets, with stricter checks on pasted payment requests and names.
- Refused a pasted payment request whose text named another amount, network or .dusk name than its link, and caught look-alike dots in names. ([PR #74](https://github.com/dusk-network/app-core/pull/74), [Release v0.18.0](https://github.com/dusk-network/app-core/releases/tag/v0.18.0), [PR #75](https://github.com/dusk-network/app-core/pull/75), [Release v0.19.0](https://github.com/dusk-network/app-core/releases/tag/v0.19.0))
- Explained in the refusal which part disagreed, and offered the person's own profiles and contacts before guessing a .dusk name. ([PR #77](https://github.com/dusk-network/app-core/pull/77), [Release v0.20.0](https://github.com/dusk-network/app-core/releases/tag/v0.20.0))

## Hyperlane-dusk

Hardened the Dusk port of Hyperlane, a system for passing messages between chains, for a testnet deployment with Sepolia.
- Reduced how fast the contracts' stored data could grow, by keeping message IDs instead of full messages and by limiting growth per transaction. ([PR #13](https://github.com/dusk-network/hyperlane-dusk/pull/13), [PR #14](https://github.com/dusk-network/hyperlane-dusk/pull/14))
- Added tools that let outside operators run validators for messages from Dusk to Sepolia without a Dusk account. ([PR #21](https://github.com/dusk-network/hyperlane-dusk/pull/21))
- Added deployment of test stablecoins issued on Dusk, EURd and USDd, and corrected delivery prices to match Sepolia's fees. ([PR #17](https://github.com/dusk-network/hyperlane-dusk/pull/17))

## Plonk

Replaced unchecked decoding of raw keys in PLONK, Dusk's zero-knowledge proof library, with safe interfaces. ([PR #1022](https://github.com/dusk-network/plonk/pull/1022))
