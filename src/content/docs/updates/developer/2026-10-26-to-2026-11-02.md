This update covers verified engineering progress during the previous seven days. Work in private repositories is summarized without private links or implementation identities; links to public changes appear directly beside the summaries they support.

## Rusk

Public change: [Release dusk-rusk-1.7.2](https://github.com/dusk-network/rusk/releases/tag/dusk-rusk-1.7.2).
### Core

Released Rusk 1.7.2 for mainnet and testnet, a hotfix that improved how nodes managed resources when running smart contracts and made storage handling more stable.
### Node VM (Private Repositories)

Hardened the Rusk node's smart contract engine, built on the Wasmtime WebAssembly runtime, and how it handled stored contract code, the work behind the Rusk 1.7.2 hotfix.

## Node installer

Released node installer 0.5.23, which updated the Rusk node software it installed to version 1.7.2 for mainnet and testnet.
- Updated the installer script and its ruskquery helper tool to version 0.5.23. ([PR #203](https://github.com/dusk-network/node-installer/pull/203), [Commit 5edfbe49](https://github.com/dusk-network/node-installer/commit/5edfbe49c64fd712e5a411e2d09e4e8bf5c88f25))
- Pointed the installer's download of its additional scripts and configurations back to the main branch after pinning it to the 0.5.23 release; the install command people run did not change. ([Commit a77ec8d3](https://github.com/dusk-network/node-installer/commit/a77ec8d349ce4d08037c99a5bc0b50d65929330d))

## Several recovery phrases in one wallet

Added support for keeping several recovery phrases in the wallet extension and web wallet, all unlocked with one password.
- Added wallet groups to the profile switcher, removed the password prompt when switching between wallets, and named the source wallet on every review and site request, so it was always clear which wallet was signing. ([PR #162](https://github.com/dusk-network/wallet/pull/162), [PR #1009](https://github.com/dusk-network/web-wallet/pull/1009))
- Fixed the extension's Lock and auto-lock messages, which had miscounted the stored wallets, and combined a session's first .dusk name lookups into one request to the node. ([PR #165](https://github.com/dusk-network/wallet/pull/165))
- Added the names of profiles from the other stored wallets to the web wallet's Send, address card and Done screens, in place of an offer to save them as contacts. ([PR #1018](https://github.com/dusk-network/web-wallet/pull/1018), [PR #1019](https://github.com/dusk-network/web-wallet/pull/1019), [PR #1020](https://github.com/dusk-network/web-wallet/pull/1020))

## Networks package

- Added network files for mainnet, testnet and devnet (endpoints, contract IDs and DuskEVM bridge contracts), replacing per-app copies that had drifted apart. ([PR #1](https://github.com/dusk-network/networks/pull/1), [Commit 5571c7c2](https://github.com/dusk-network/networks/commit/5571c7c2129335a97fdb9c9512e3a93ea7521c0c))

- Added shared rules in 0.3.0 for DuskEVM bridge calls, Dusk account keys and transfer gas, so every app handled them the same way. ([PR #5](https://github.com/dusk-network/networks/pull/5))
- Set up releases from version tags to npm, JSR and GitHub, and after the first release moved to npm trusted publishing, removing the stored token. ([PR #2](https://github.com/dusk-network/networks/pull/2), [PR #3](https://github.com/dusk-network/networks/pull/3))

## Package install safeguards

Hardened how the wallets, explorer, Connect and App-core installed third-party code packages, with checks on every build.
- Blocked install scripts that were not explicitly allowed; packages from git, local files or web addresses; and outside package versions younger than the minimum age. Made every build check release ages and npm packages' registry signatures. ([PR #50](https://github.com/dusk-network/app-core/pull/50), [PR #61](https://github.com/dusk-network/connect/pull/61), [PR #308](https://github.com/dusk-network/explorer/pull/308), [PR #1016](https://github.com/dusk-network/web-wallet/pull/1016))
- Shortened the wait before using a new package version from seven days to 12 hours in App-core and the extension, so an urgent dependency fix could land the same day. ([PR #52](https://github.com/dusk-network/app-core/pull/52), [PR #170](https://github.com/dusk-network/wallet/pull/170))
- Changed App-core's and the extension's npm requirement from exactly 11.18.0 to 11.18.0 or newer, matching the explorer, Connect and web wallet, and kept 11.18.0 as the minimum because older npm versions silently ignored these install rules. ([PR #51](https://github.com/dusk-network/app-core/pull/51), [PR #169](https://github.com/dusk-network/wallet/pull/169))

## Development tooling

Updated and trimmed the developer tools behind Connect, the explorer and both wallets, without changing how the apps worked.
- Updated Vite, Vitest and related test tools to their latest releases, which cleared every flagged development-tool finding in Connect and the extension and halved them in the explorer. ([PR #59](https://github.com/dusk-network/connect/pull/59), [PR #60](https://github.com/dusk-network/connect/pull/60), [PR #306](https://github.com/dusk-network/explorer/pull/306), [PR #166](https://github.com/dusk-network/wallet/pull/166), [PR #1014](https://github.com/dusk-network/web-wallet/pull/1014))
- Removed unused build and test packages, including the extension's unused Storybook, and switched to standard lint settings; the explorer's dependencies fell from 536 to 319 packages, leaving fewer outside packages to trust. ([PR #307](https://github.com/dusk-network/explorer/pull/307), [PR #1015](https://github.com/dusk-network/web-wallet/pull/1015), [PR #167](https://github.com/dusk-network/wallet/pull/167))

## Dusk website (Private Repositories)

Reworked dusk.network to build as a static site from articles and pages stored alongside its code, retiring the separate content management server.
- Updated the website's build and test tooling in one batch, with newly published packages accepted after a 12-hour wait instead of seven days.
- Updated research paper descriptions shown in search results to end on a whole sentence instead of a cut-off word.
