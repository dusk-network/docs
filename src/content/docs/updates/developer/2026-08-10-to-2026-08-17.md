This update covers qualifying public-repository engineering activity during the previous seven days. Every included change is listed in the source ledger below.

## Development summary

- **Docs:** Added dedicated update sections and crawler metadata, making documentation updates easier to find, link and share.
  - Published conventional crawler entry points and default social preview metadata, backed by machine-file tests and the complete validation gate.
  - Added dedicated Network Updates and Developer Updates sections, including verified hard-fork history, a newest-first developer index and an authoring template.

- **Zk-tools:** Expanded zk-tools with shared validation, a public website and Solidity verifier tooling, making the toolkit easier to explore and integrate.
  - Added tooling for generating and validating a Groth16 verifier for Solidity.
  - Added the first zk-tools website and fixed its Pages deployment runtime.
  - Consolidated stable-toolchain validation into a shared workspace job with reusable build artifacts.

- **Duskevm-genesis:** Pinned devnet rehearsal inputs to the intended chain state, improving repeatability across network tests.
  - Published reproducible devnet rehearsal inputs with refreshed L1 anchors and checksums.

- **Merkle:** Added stronger checks when loading archived Merkle trees, so inconsistent tree data is rejected before use.
  - Added checks for archived Merkle-tree data while preserving valid cached values.

- **Jubjub-schnorr:** Hardened secret-key and multisignature handling to make misuse harder and validation more explicit.
  - Strengthened multisignature state handling and validation by consuming nonces once, binding both keys, checking transcripts and shares, and deduplicating aggregate-key derivation.
  - Expanded lint coverage across feature combinations and compilation targets.
  - Reduced accidental secret-key exposure and misuse by redacting debug output, removing unsafe convenience traits and pinning those guarantees with compile checks.

- **Piecrust:** Optimized macOS ARM validation to retain coverage with fewer unnecessary hosted-runner minutes.
  - Reduced routine CI cost by gating paid macOS ARM checks while retaining automatic main-branch, labeled and manual coverage.

- **Plonk:** Strengthened proof validation so malformed or inconsistent inputs fail earlier.
  - Expanded soundness checks for malformed inputs and edge cases.
  - Added stricter checks when loading prover data, commitment keys and compressed circuit payloads.

- **Dusk-bytes:** Strengthened byte-input validation so malformed serialized values fail earlier and more predictably.
  - Strengthened byte parsing by reading complete serialized values and rejecting odd-length hexadecimal input before indexing.

- **Jubjub-elgamal:** Added checked decoding for archived ElGamal ciphertexts, rejecting malformed serialized values at the boundary without changing valid round trips.
