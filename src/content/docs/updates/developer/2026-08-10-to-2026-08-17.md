This update covers qualifying public-repository engineering activity during the previous seven days. Links to public changes appear directly beside the summaries they support.

## Docs

Added dedicated update sections and crawler metadata, making documentation updates easier to find, link and share. ([PR #140](https://github.com/dusk-network/docs/pull/140), [PR #141](https://github.com/dusk-network/docs/pull/141))
- Published conventional crawler entry points and default social preview metadata, backed by machine-file tests and the complete validation gate.
- Added dedicated Network Updates and Developer Updates sections, including verified hard-fork history, a newest-first developer index and an authoring template.

## Zk-tools

Expanded zk-tools with shared validation, a public website and Solidity verifier tooling, making the toolkit easier to explore and integrate. ([PR #9](https://github.com/dusk-network/zk-tools/pull/9), [PR #10](https://github.com/dusk-network/zk-tools/pull/10), [PR #11](https://github.com/dusk-network/zk-tools/pull/11), [PR #12](https://github.com/dusk-network/zk-tools/pull/12))
- Added tooling for generating and validating a Groth16 verifier for Solidity.
- Added the first zk-tools website and fixed its Pages deployment runtime.
- Consolidated stable-toolchain validation into a shared workspace job with reusable build artifacts.

## Duskevm-genesis

Pinned devnet rehearsal inputs to the intended chain state, improving repeatability across network tests. ([PR #12](https://github.com/dusk-network/duskevm-genesis/pull/12), [PR #11](https://github.com/dusk-network/duskevm-genesis/pull/11), [PR #13](https://github.com/dusk-network/duskevm-genesis/pull/13), [PR #14](https://github.com/dusk-network/duskevm-genesis/pull/14))
- Published reproducible devnet rehearsal inputs with refreshed chain anchors and checksums.

## Merkle

Added stronger checks when loading archived Merkle trees, so inconsistent tree data is rejected before use. ([PR #112](https://github.com/dusk-network/merkle/pull/112), [PR #113](https://github.com/dusk-network/merkle/pull/113), [PR #122](https://github.com/dusk-network/merkle/pull/122), [PR #120](https://github.com/dusk-network/merkle/pull/120))
- Kept valid archived data loading as before.

## Jubjub-schnorr

Hardened secret-key and multisignature handling to make misuse harder and validation more explicit. ([PR #46](https://github.com/dusk-network/jubjub-schnorr/pull/46), [PR #56](https://github.com/dusk-network/jubjub-schnorr/pull/56), [PR #57](https://github.com/dusk-network/jubjub-schnorr/pull/57), [PR #47](https://github.com/dusk-network/jubjub-schnorr/pull/47), [PR #49](https://github.com/dusk-network/jubjub-schnorr/pull/49), [PR #61](https://github.com/dusk-network/jubjub-schnorr/pull/61), [PR #62](https://github.com/dusk-network/jubjub-schnorr/pull/62), [PR #66](https://github.com/dusk-network/jubjub-schnorr/pull/66), [PR #68](https://github.com/dusk-network/jubjub-schnorr/pull/68), [PR #67](https://github.com/dusk-network/jubjub-schnorr/pull/67), [PR #70](https://github.com/dusk-network/jubjub-schnorr/pull/70), [PR #72](https://github.com/dusk-network/jubjub-schnorr/pull/72))
- Strengthened multisignature state handling and validation by consuming nonces once, binding both keys, checking transcripts and shares, and deduplicating aggregate-key derivation.
- Expanded lint coverage across feature combinations and compilation targets.
- Reduced accidental secret-key exposure and misuse by redacting debug output, removing unsafe convenience traits and pinning those guarantees with compile checks.

## Piecrust

Optimized macOS ARM validation to retain coverage with fewer unnecessary hosted-runner minutes. ([PR #503](https://github.com/dusk-network/piecrust/pull/503), [PR #504](https://github.com/dusk-network/piecrust/pull/504))
- Reduced routine CI cost by gating paid macOS ARM checks while retaining automatic main-branch, labeled and manual coverage.

## Plonk

Strengthened proof validation so malformed or inconsistent inputs fail earlier. ([PR #904](https://github.com/dusk-network/plonk/pull/904), [PR #905](https://github.com/dusk-network/plonk/pull/905), [PR #907](https://github.com/dusk-network/plonk/pull/907), [PR #909](https://github.com/dusk-network/plonk/pull/909), [PR #911](https://github.com/dusk-network/plonk/pull/911), [PR #866](https://github.com/dusk-network/plonk/pull/866), [PR #912](https://github.com/dusk-network/plonk/pull/912), [PR #915](https://github.com/dusk-network/plonk/pull/915))
- Expanded soundness checks for malformed inputs and edge cases.
- Added stricter checks when loading proof data and compressed circuits.

## Dusk-bytes

Strengthened byte-input validation so malformed serialized values fail earlier and more predictably. ([PR #40](https://github.com/dusk-network/dusk-bytes/pull/40), [PR #41](https://github.com/dusk-network/dusk-bytes/pull/41))
- Strengthened byte parsing by reading complete serialized values and rejecting odd-length hexadecimal input before indexing.

## Jubjub-elgamal

Added checked decoding for archived ElGamal ciphertexts, rejecting malformed serialized values at the boundary without changing valid round trips. ([PR #30](https://github.com/dusk-network/jubjub-elgamal/pull/30))
