This update covers qualifying public-repository engineering activity during the previous seven days. Every included change is listed in the source ledger below.

## Development summary

- **Docs:** Readers gained clearer, more discoverable documentation and a durable home for ongoing updates.
  - Published conventional crawler entry points and default social preview metadata, backed by machine-file tests and the complete validation gate.
  - Added dedicated Network Updates and Developer Updates sections, including verified hard-fork history, a newest-first developer index and an authoring template.

- **Zk-tools:** Tooling became easier to validate, explore and integrate.
  - Added tooling for generating and validating a Groth16 verifier for Solidity.
  - Added the first zk-tools website and fixed its Pages deployment runtime.
  - Consolidated stable-toolchain validation into a shared workspace job with reusable build artifacts.

- **Duskevm-genesis:** Network rehearsals became easier to reproduce against the intended chain state.
  - Published pinned challenger prestate and reproducible H2 devnet rehearsal artifacts, including refreshed L1 anchors, checksums and validation evidence.

- **Merkle:** Corrupted or inconsistent archived trees were rejected before use.
  - Added checked archive validation for Merkle tree paths, opening positions and structural invariants while preserving valid cached aggregates.

- **Jubjub-schnorr:** Secret and multisignature handling became more explicit, validated and resistant to misuse.
  - Strengthened multisignature state handling and validation by consuming nonces once, binding both keys, checking transcripts and shares, and deduplicating aggregate-key derivation.
  - Expanded lint coverage across feature combinations and compilation targets.
  - Reduced accidental secret-key exposure and misuse by redacting debug output, removing unsafe convenience traits and pinning those guarantees with compile checks.

- **Piecrust:** Validation coverage stayed available with fewer unnecessary hosted-runner minutes.
  - Reduced routine CI cost by gating paid macOS ARM checks while retaining automatic main-branch, labeled and manual coverage.

- **Plonk:** Malformed or inconsistent proof-system inputs were rejected earlier and more predictably.
  - Extended point-soundness coverage so malformed assignments were rejected without panics and curve-addition edge cases were tested in isolation.
  - Rejected compressed circuit payloads containing trailing data after the expected message body.
  - Added a targeted soundness regression proving the logic gadget binds its per-quad product witness.
  - Validated cached prover evaluations against reconstructed domains during checked deserialization.
  - Stored commitment-key points canonically and validated them before constructing live public parameters.

- **Dusk-bytes:** Malformed or incomplete byte input was rejected earlier and more predictably.
  - Strengthened byte parsing by reading complete serialized values and rejecting odd-length hexadecimal input before indexing.

- **Jubjub-elgamal:** Archived ciphertext handling became stricter without changing valid round trips.
  - Added checked decoding for archived ElGamal ciphertexts so malformed serialized values were rejected at the boundary.
