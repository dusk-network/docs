This update covers verified engineering progress during the previous seven days. Work in private repositories is summarized without private links or implementation identities; links to public changes appear directly beside the summaries they support.

## Rusk

Public change: [Release dusk-rusk-1.7.3](https://github.com/dusk-network/rusk/releases/tag/dusk-rusk-1.7.3).
### Core (Public + Private Repo)

Released Rusk 1.7.3, the Dusk node software, as a security update for mainnet and testnet, announced on 5 Nov.
### Private

Hardened the Rusk node's block, transaction and consensus checks, and reworked shielded wallet sync to read finalized state in resumable pages.
    - Reworked shielded balance sync in the command-line Rusk wallet to read finalized state from the node in bounded pages and pick up where it stopped after an interrupted connection.
    - Simplified how the node's RUES interface, its event and query API, built responses, with the same formats and status codes as before.
### Piecrust (Private Repo)

Hardened Piecrust, the virtual machine behind Dusk smart contracts, and reworked how nodes store and read contract state.
- Updated nodes to convert an older contract-state store to the current format when they open it, keeping the original for rollback, so an upgrade needed no separate offline step.
- Added a query mode in which read-only requests kept their own snapshot of finalized state without holding up block finalization.
- Removed an unused state-migration interface.
