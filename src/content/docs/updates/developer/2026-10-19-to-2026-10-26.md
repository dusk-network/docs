This update covers verified engineering progress during the previous seven days. Work in private repositories is summarized without private links or implementation identities; links to public changes appear directly beside the summaries they support.

## DuskEVM


### Explorer (Private Repositories)

Updated the DuskEVM Explorer testnet frontend to a maintained runtime release, keeping the service on supported software.
### Core (Private Repositories)

Reworked how DuskEVM verified Dusk blocks through a compact per-block record of events, and cut the DuskEVM adapter's load on Dusk nodes.
- Added a compact record of each Dusk block's events that DuskEVM's services and its dispute-settlement software checked before trusting a block. Stored proof data stopped depending on a node's archive, and the adapter's database took about half the space.
- Reduced the adapter's requests to Dusk nodes: repeated block and event lookups were cached, request bursts were capped and paced, and the adapter waited for new-block announcements instead of asking for the latest block four times a second.

## Rusk


### Piecrust (Private Repo)

Reworked how the Piecrust virtual machine saved contract state to disk, and strengthened how it handled contract memory.
- Reworked state saving so each save wrote only the data that changed and completed in one all-or-nothing step, with a tool that moved existing stores to the new format.
- Made memory handling more defensive.
- Optimized new state snapshots by storing each one against the snapshot it directly built on.
### Core (Private Repo)

Added the block height, block hash and state root to Rusk's contract query responses, so apps making several reads could confirm they came from one block.
- Added three response headers naming the block each query read, taken from the block the query opened on even when a newer block arrived while it ran.
- Handled more mempool edge cases.
- Prepared for the Cerberus hard fork activation and its accompanying features.
- Increased end-to-end test coverage from the mempool to preverification.

## .dusk names in Dusk apps

Added .dusk name support across Dusk's wallets and explorer, so a readable name could stand in for a long account address when sending or searching.
- Added .dusk name search to the explorer on mainnet and testnet, opening the named account's page, and showed each account's verified primary name on account pages and on the sender and receiver of public transactions. ([PR #287](https://github.com/dusk-network/explorer/pull/287))
- Added the account's verified .dusk name to the profiles the browser extension wallet shared with connected sites, and showed the name in approval pop-ups. ([PR #128](https://github.com/dusk-network/wallet/pull/128))
- Added .dusk names as Send recipients in the browser extension and web wallets, showing which of the name's addresses was public and which was shielded before sending. ([PR #124](https://github.com/dusk-network/wallet/pull/124), [PR #964](https://github.com/dusk-network/web-wallet/pull/964))
- Updated the Dusk Domains entry on the documentation's ecosystem page to describe readable .dusk names for Dusk accounts, with records and subnames. ([PR #159](https://github.com/dusk-network/docs/pull/159))

## Gas defaults in Dusk wallets

Updated the default gas limits in the browser extension and web wallets to per-operation values based on measured usage, with the same numbers in both.
- Set a public transfer's default at 2.5 million gas and shielded transfers, shield and unshield at 50 million. The web wallet had used 100 million for every operation, which showed a 0.1 DUSK maximum fee on a public transfer. ([PR #122](https://github.com/dusk-network/wallet/pull/122), [PR #972](https://github.com/dusk-network/web-wallet/pull/972))

## Hide balances in Dusk wallets

Added a Hide balances eye button to the browser extension and web wallets, masking every balance on screen until it was pressed again.
- Masked the total, its public and shielded split, token balances, spendable amounts, and staked amounts and rewards, with screen readers hearing "hidden" in place of each amount. ([PR #132](https://github.com/dusk-network/wallet/pull/132), [PR #971](https://github.com/dusk-network/web-wallet/pull/971))

## Wallet

Simplified the browser extension wallet's review screens, moving gas presets behind an Edit button and removing a Cancel button that duplicated Back. ([PR #129](https://github.com/dusk-network/wallet/pull/129))

## Web-wallet

Simplified the web wallet's wording across Send, Receive, balances, Settings and Bridge withdrawals, replacing long warnings and statuses with short lines.
- Shortened each Bridge withdrawal status to one label with at most one line under it, such as "Waiting period" with the date the claim opened, and marked proving and claiming as step 1 and step 2. ([PR #973](https://github.com/dusk-network/web-wallet/pull/973))
- Replaced the three-line warning for sending to your own address with "This is your own address.", labelled Spendable as public or shielded, and showed the QR scan button only on devices with a camera. ([PR #967](https://github.com/dusk-network/web-wallet/pull/967))

## Whitepaper

Replaced the published whitepaper PDF with a rebuild that carried its title, authors, subject and keywords, so search engines could list it correctly. ([PR #2](https://github.com/dusk-network/whitepaper/pull/2))

## Dusk website (Private Repo)

Added a research hub and an audits page to the Dusk website, giving each research paper its own page that search engines and Google Scholar could index.
- Added a research hub and one page per research paper, with citation details for Google Scholar and a PDF download, in place of off-site PDF links alone.
- Added an audits page that listed Dusk's third-party audits, each linked to its report in Dusk's public audits repository.
- Corrected menu and footer links that went through a redirect, turned the news archive's Load more button into a link search engines could follow, and replaced titles cut off mid-word with full headings.
- Added a one-line summary under each paper's title on the research hub.

## Hedger (Private Repositories)

Documented the Hedger protocol in a specification that described each circuit rule, contract call and transaction flow as the code implemented them.
- Documented the protocol's notation, proof inputs, contract checks and step-by-step flows, and listed where the code did not yet follow the specification.

## Phoenix specification (Private Repo)

Updated the Phoenix transaction model paper to Version 2.1, documenting the circuit's checks on keys, notes and encryption values and refreshing its circuit size figures.
- Updated the paper to Version 2.1 with circuit size figures measured on the current circuits, a corrected diagram and title and keyword details that help search engines index the PDF.
- Documented checks the transaction circuit enforced but the paper had not described: valid key points, distinct spent notes, and separate nonzero random values in the sender's encrypted details.
- Corrected cross-references in both Phoenix paper versions that pointed note encryption to the hash-function section instead of the encryption section.

## Dusk Whitepaper (Private Repo)

Added title, author, subject and keyword details to the Dusk Whitepaper PDF, so search engines and Google Scholar could index it properly.
- Added the paper's title, authors, subject and keywords to the PDF's document details, leaving the paper's text unchanged.
