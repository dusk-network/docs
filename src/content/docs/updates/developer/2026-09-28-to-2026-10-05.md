This update covers verified engineering progress during the previous seven days. Work in private repositories is summarized without private links or implementation identities; links to public changes appear directly beside the summaries they support.

## Rusk


### Piecrust (Private Repositories)

Expanded Piecrust state compatibility and execution controls while strengthening validation coverage.
- Added a legacy finalization mode for historical chain replay while retaining strict behavior for later state. Preserved compatibility with earlier state-finalization rules.
- Preserved contract memory lengths beyond the legacy 32-bit limit with versioned persisted-state encoding and checked promotion. Protected wide-memory state from truncation during persistence.
- Added protocol-policy control for retaining nested events from reverted calls while preserving legacy receipt behavior.
- Validated oversized inter-contract method names before text parsing across legacy and host-backed calls. Reduced unnecessary processing for inputs that exceeded the method-name limit.
- Preserved historical event receipts for pre-Boreas initializer failures while keeping rolled-back state unchanged.
- Added local and continuous-integration coverage reporting for Piecrust and Crumbles, including changed-line checks.

## Rusk (continued)


### Node (Private Repo)

Strengthened Rusk node recovery, transaction readmission, and chain-state accounting.
- Added operator-controlled circulating-supply validation with recoverable state updates and bounded height-index scans. Reduced repeated database work during chain synchronization while preserving atomic state transitions.
- Reworked reverted-transaction readmission around shared policy checks, atomic storage, and typed outcomes. Made rollback handling more consistent under capacity and policy constraints.
- Improved full-pool retry guidance and coordinated smaller corrections across node and wallet paths.
- Centralized HTTP error classification for status codes, public messages, and telemetry categories. Kept service-unavailable responses consistent across HTTP paths.
- Simplified database and serialization paths by removing repeated conversion and abstraction layers.
### Protocol (Private Repo)

Updated Rusk protocol schedules and rule selection across node execution and the virtual machine.
- Defined reward handling for successors of authenticated emergency blocks without changing block or wire formats.
- Replaced scattered feature gates with typed schedules selected consistently at each block height. Aligned feature activation across node, execution, and virtual-machine paths.
- Added chain-ID checks during transaction preverification and carried selected chain IDs into shielded deployments. Reduced cross-chain transaction handling mismatches.
- Cached per-key BLS aggregation coefficients with bounds while preserving aggregation results and error behavior. Reduced repeated consensus-key computation.

## Jubjub-schnorr

Strengthened Schnorr signing and multisignature validation across equivalent generator encodings and invalid participant keys.
- Rejected invalid or empty participant-key sets across multisignature signing, share verification, combination, and aggregation. ([PR #91](https://github.com/dusk-network/jubjub-schnorr/pull/91))

## Jubjub

Strengthened JubJub key-exchange and secret-handling boundaries by rejecting invalid peer points and erasing temporary entropy after scalar generation.
- Rejected invalid and small-order public points in Diffie-Hellman key exchange while preserving results for prime-order points. ([PR #178](https://github.com/dusk-network/jubjub/pull/178))
- Wiped the scalar-generation entropy buffer after reduction whenever the zeroize feature is enabled. ([PR #179](https://github.com/dusk-network/jubjub/pull/179))

## Bls12\_381

Corrected hash-to-curve edge cases and bounded unencodable XMD configurations, aligning exceptional inputs with RFC 9380 while preserving ordinary outputs.
- Rejected oversized domain-separation configurations whose processed length cannot be encoded, with a focused regression test. ([PR #197](https://github.com/dusk-network/bls12_381/pull/197))
- Handled zero and isogeny-kernel inputs according to RFC 9380 and added differential coverage for the exceptional cases. ([PR #195](https://github.com/dusk-network/bls12_381/pull/195))

## Plonk

- Removed unused polynomial powers, aggregate-witness challenge work, and oversized multiplication domains. ([PR #978](https://github.com/dusk-network/plonk/pull/978))
- Added exact proof decoding, canonical key parsing, and full-width decomposition constraints alongside compatibility checks. ([PR #982](https://github.com/dusk-network/plonk/pull/982))
