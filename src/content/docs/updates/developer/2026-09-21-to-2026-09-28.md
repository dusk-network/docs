This update covers verified engineering progress during the previous seven days. Work in private repositories is summarized without private links or implementation identities; links to public changes appear directly beside the summaries they support.

## Rusk


### Core (Private Repo)

Updated proof-version selection and transaction-data pricing, alongside clearer build guidance.
- Changed proof verification to use the versions supplied by the calling application.
- Clarified build-cache guidance, linked archive changelog entries, and added a check for the archive benchmark.
- Added activation-controlled pricing for transaction data, allowing its data size to contribute to the gas cost.
### Piecrust (Private Repo)

Updated contract-state handling and execution checks to improve consistency across saved states and contract runs.
- Documented the order used to finalize contract execution.
- Added tests covering contract initialization when execution runs out of gas.
- Added a check that exercises process-signal forwarding.
- Added activation controls for the contract-state format transition.
- Extended saved contract-state commitments to include memory size.

## Forge

Restored reproducible smart-contract project builds and corrected event registration in the starter template.
- Registered the counter template's event type and corrected the event-registration guide so generated projects could decode emitted events. ([PR #43](https://github.com/dusk-network/forge/pull/43))
- Pinned Rust 1.95 and compatible dependencies, made dependency updates respect that compiler version, and restored CLI tests and code-quality checks. ([PR #48](https://github.com/dusk-network/forge/pull/48))

## Bls12\_381

Updated the hash-to-curve interface with stable compatibility guarantees and expanded checks for reduced-feature builds.
- Stabilized the opt-in hash-to-curve interface while preserving its existing behavior and compatibility alias, and added checks against RFC 9380 reference vectors. ([PR #193](https://github.com/dusk-network/bls12_381/pull/193))
- Repaired tests for reduced-feature configurations and included them in the existing test and code-quality checks. ([PR #190](https://github.com/dusk-network/bls12_381/pull/190))

## Proof-wire blinding

Updated proof masking and setup-parameter capacity across the native and WebAssembly proof tooling.
- Added extra random masking to three proof wires to match their two verification openings, with corresponding tests. ([PR #976](https://github.com/dusk-network/plonk/pull/976), [PR #14](https://github.com/dusk-network/zk-tools/pull/14))
- Increased the setup converter's parameter allocation by three powers to accommodate additional proof-masking values. ([Commit 384608ae](https://github.com/dusk-network/trusted-setup/commit/384608ae361325f60b8af92d8da4407e9615c797))
