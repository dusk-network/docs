## DuskEVM SDK

- Standardized sandbox request settlement across success, failure, abort, timeout, and worker-exit paths. ([PR #11](https://github.com/dusk-network/exu/pull/11))

## Connect

Expanded provider coordination, transaction waiting, account encoding, and integration guidance for more reliable dApp connections.
- Added validated conversion between Base58 Moonlight accounts and their 96-byte hexadecimal public-key representation. ([PR #36](https://github.com/dusk-network/connect/pull/36))
- Documented chain IDs, signature envelopes, transport-safe contract arguments, and unverified display metadata. ([PR #34](https://github.com/dusk-network/connect/pull/34))
- Enforced active-provider selection for stateful wallet operations and event subscriptions. ([PR #33](https://github.com/dusk-network/connect/pull/33))
- Added queued execution frames during subscription setup while keeping timeouts, aborts, and transport failures retryable. ([PR #30](https://github.com/dusk-network/connect/pull/30))
- Prevented another object with the same UUID from replacing an explicitly selected provider. ([PR #31](https://github.com/dusk-network/connect/pull/31))
- Clarified successful, failed, and unknown transaction outcomes instead of treating malformed payloads as success. ([PR #32](https://github.com/dusk-network/connect/pull/32))
- Prevented Promise resolution from invoking generated contract methods by keeping contract facets non-thenable. ([PR #29](https://github.com/dusk-network/connect/pull/29))
- Consolidated normalization helpers and removed dead internal typing without changing the public surface. ([PR #22](https://github.com/dusk-network/connect/pull/22))
- Consolidated receipt waiting, transport-error normalization, theme tokens, and demo styles across repeated paths. ([PR #21](https://github.com/dusk-network/connect/pull/21))
- Updated node state from wallet capabilities while preserving the existing node when capability data was absent. ([PR #19](https://github.com/dusk-network/connect/pull/19))

- Standardized wallet lifecycle and approval mutations so failures could not leave partially replaced state. ([PR #95](https://github.com/dusk-network/wallet/pull/95))
- Standardized transaction construction per wallet, network, and profile while reserving sequential Moonlight nonces. ([PR #96](https://github.com/dusk-network/wallet/pull/96))

- Supported current and legacy execution payloads while preserving stronger terminal evidence and later finalization. ([PR #76](https://github.com/dusk-network/wallet/pull/76))
- Removed unused internal helpers while preserving runtime behavior and public wallet surfaces. ([PR #87](https://github.com/dusk-network/wallet/pull/87))
- Consolidated equivalent UI command dispatch across extension and desktop runtimes while preserving platform-specific behavior. ([PR #86](https://github.com/dusk-network/wallet/pull/86))
- Consolidated engine messaging, retry, configuration, status, and gas-control paths across browser hosts. ([PR #85](https://github.com/dusk-network/wallet/pull/85))
