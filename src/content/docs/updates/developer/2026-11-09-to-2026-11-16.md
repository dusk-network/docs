This update covers verified engineering progress during the previous seven days. Work in private repositories is summarized without private links or implementation identities; links to public changes appear directly beside the summaries they support.

## Rusk


### Piecrust (Private Repositories)

Added an optional archive of past contract state to Piecrust, the virtual machine behind Dusk smart contracts, and an opt-in standard WebAssembly memory mode.
- Added an optional archive store that kept contract state for every past block height, so archive nodes could answer contract queries at earlier heights.
- Added an opt-in mode that followed standard WebAssembly memory rules, while existing contracts and past blocks kept their original behaviour.
### Core (Private Repo)

Moved the Rusk node, Dusk's node software, onto Piecrust's snapshot store for contract state and hardened how it recovered and checked its state.
- Moved the node onto Piecrust's snapshot store, converting an existing store once when it opened, and had it open an existing state once at startup instead of twice.

## Node installer

Updated the node installer's mainnet and testnet bootstrap lists, the first peers a new node contacts, from three to six nodes, so one outage could not remove all. ([PR #205](https://github.com/dusk-network/node-installer/pull/205))

## App-core package

Released app-core 0.10.0 to 0.17.0, the shared code behind both wallets, with stricter checks on payment links, amounts, names and recovery words.
- Refused payment links with a second recipient or an amount that was not a plain number, and asked which amount was meant when "1.000" could be read two ways. ([PR #66](https://github.com/dusk-network/app-core/pull/66), [Release v0.10.0](https://github.com/dusk-network/app-core/releases/tag/v0.10.0), [PR #69](https://github.com/dusk-network/app-core/pull/69), [Release v0.13.0](https://github.com/dusk-network/app-core/releases/tag/v0.13.0), [PR #67](https://github.com/dusk-network/app-core/pull/67), [Release v0.11.0](https://github.com/dusk-network/app-core/releases/tag/v0.11.0))
- Refused a profile name that matched another profile's .dusk name, look-alike letters included, and asked before saving one that started like another name. ([PR #68](https://github.com/dusk-network/app-core/pull/68), [Release v0.12.0](https://github.com/dusk-network/app-core/releases/tag/v0.12.0), [PR #70](https://github.com/dusk-network/app-core/pull/70), [Release v0.14.0](https://github.com/dusk-network/app-core/releases/tag/v0.14.0))
- Set a default gas price that stayed at the minimum while waiting transactions fitted in the next block. ([PR #71](https://github.com/dusk-network/app-core/pull/71), [Release v0.15.0](https://github.com/dusk-network/app-core/releases/tag/v0.15.0))
- Added a recovery-word check that answered only yes or no, and the word-list lookup behind the wallets' suggestions, with nothing fetched, logged or stored. ([PR #72](https://github.com/dusk-network/app-core/pull/72), [Release v0.16.0](https://github.com/dusk-network/app-core/releases/tag/v0.16.0), [Release v0.17.0](https://github.com/dusk-network/app-core/releases/tag/v0.17.0), [PR #73](https://github.com/dusk-network/app-core/pull/73))

## Hyperlane-dusk

Hardened the Dusk port of Hyperlane, a system for passing messages between chains, and documented how it differed from the Ethereum version.
- Reserved each message's delivery before the follow-up code it triggered ran, so one message could not be processed twice, and recorded the same gas plus overhead that a payment quote charged. ([PR #11](https://github.com/dusk-network/hyperlane-dusk/pull/11))
- Replaced about 11,500 lines of process documents and review tooling with a README and two short guides covering known limitations and how to run it. ([PR #12](https://github.com/dusk-network/hyperlane-dusk/pull/12))
