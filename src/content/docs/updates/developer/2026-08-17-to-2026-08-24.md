## Jubjub-schnorr

Simplified Jubjub Schnorr test initialization and serialization internals while preserving encoded formats and validation behavior.

## Jubjub

Removed a test-only hashing dependency while preserving generator output and reducing the development graph.

## Dusk-bytes

Simplified Dusk Bytes serialization internals and feature selection while preserving checked parsing and default macro behavior.
- Borrowed the validated input prefix directly instead of copying it before deserialization, with short-input and trailing-byte handling unchanged. ([PR #47](https://github.com/dusk-network/dusk-bytes/pull/47))
- Made derive macros optional behind a default-on feature, preserving existing behavior while allowing serialization-only consumers to omit the dependency. ([PR #43](https://github.com/dusk-network/dusk-bytes/pull/43))

## Plonk

Optimized and hardened PLONK proving, verification, compressed-circuit handling, and dependencies while preserving proof formats and compatibility.
- Updated compressed-circuit dependencies while preserving byte-identical artifacts and cross-version reconstruction. ([PR #945](https://github.com/dusk-network/plonk/pull/945))
- Replaced the deprecated test-only tempdir package with tempfile while preserving debugger temporary-directory behavior. ([PR #947](https://github.com/dusk-network/plonk/pull/947))
- Updated blake2b\_simd and removed an unnecessary dependency while preserving proof, transcript, and hash outputs. ([PR #946](https://github.com/dusk-network/plonk/pull/946))
- Aligned hashbrown with the rkyv dependency graph to reduce duplicate generations without changing APIs, no\_std behavior, proofs, or serialization. ([PR #944](https://github.com/dusk-network/plonk/pull/944))
- Bound compressed-circuit allocation and rejected malformed indices, polynomial lengths, public-input positions, and curve-addition edge cases without changing valid formats. ([PR #939](https://github.com/dusk-network/plonk/pull/939), [PR #938](https://github.com/dusk-network/plonk/pull/938), [PR #936](https://github.com/dusk-network/plonk/pull/936), [PR #929](https://github.com/dusk-network/plonk/pull/929), [PR #932](https://github.com/dusk-network/plonk/pull/932))
- Cached reusable prover and verifier data, grouped multiscalar work, and parallelized independent FFT and proof stages while preserving transcript and proof outputs. ([PR #934](https://github.com/dusk-network/plonk/pull/934), [PR #928](https://github.com/dusk-network/plonk/pull/928), [PR #924](https://github.com/dusk-network/plonk/pull/924), [PR #926](https://github.com/dusk-network/plonk/pull/926), [PR #923](https://github.com/dusk-network/plonk/pull/923), [PR #922](https://github.com/dusk-network/plonk/pull/922))

## Phoenix

Hardened Phoenix Core error and buffer handling while simplifying its random-number dependency surface.
- Replaced the production rand facade with direct rand\_core traits without changing cryptographic operations or compiled behavior. ([PR #299](https://github.com/dusk-network/phoenix/pull/299))
- Validated complete AES buffer-length relationships and returned structured length errors instead of panicking on malformed helper inputs. ([PR #297](https://github.com/dusk-network/phoenix/pull/297))
- Mapped every Phoenix Core error into Dusk Bytes outcomes, replacing reachable unwinds with structured errors. ([PR #295](https://github.com/dusk-network/phoenix/pull/295))
